# Home Team Reporter

Use this skill when creating or updating **yearly Home Team report pages** on
`wiki.fosscell.org`. These pages follow a strict recipe and are highly
automatable — there are dozens of teams each year.

---

## Page naming

```
YYYY:TeamName
```

Examples: `2026:Football Team`, `2026:NITC Mime Team`, `2025:Robotics Team`.

The `YYYY:` year namespace (IDs 3000–3135) is the correct home.
Also create a **redirect** in main namespace if one doesn't exist:

```
#REDIRECT [[2026:Football Team]]
```

---

## Templates (in order)

Always read `Template:Infobox Home Team Year` and `Template:Home Team Year Report`
before writing — field names change. The order below reflects current wiki state.

### 1. Tabs (auto-generated by the report template)

The `{{Home Team Year Report}}` wrapper calls `{{Home Team Year Tabs}}` internally.
You don't need to add it separately.

### 2. `{{Home Team Year Report}}`

```wikitext
{{Home Team Year Report
| team        = NITC Football Team
| year        = 2025–26
| batch       = B25
| type        = Sports
| captain     = 
| members     = 
| image       = 
| achievements =
| participations =
| project     = 
| docs        = 
| videos      = 
| news        = 
}}
```

Fields:
- `team` — full display name (must match the main team page title)
- `year` — academic year in `YYYY–YY` format (en-dash, not hyphen)
- `batch` — cohort code, e.g. `B25`
- `type` — `Sports`, `Cultural`, or `Technical`
- `captain` — name of captain/lead
- `members` — either a wikitext table or a plain comma-separated list
- `achievements` — free text or a wikitable of results
- `participations` — a wikitable of events (columns: Event, Venue, Date, Result)
- `project` — for Technical teams only; leave blank for Sports/Cultural
- `docs` — link to docs/repo; leave blank for Sports/Cultural
- `videos` — links to performance or competition footage
- `news` — coverage links

### 3. Body sections (inside the template)

The template auto-generates:
- `== Members ==`
- `== Project ==` (if `project` is filled)
- `== Achievements ==`
- `== Participations ==`
- `== Coverage ==` (Videos + News sub-sections)
- `== See also ==`

You generally don't need to add sections manually unless there's extra content.

## Participations wikitable format

```wikitext
<tr><td>SlamDunk at NIT Surathkal</td><td>NIT Surathkal</td><td>14–16 March 2026</td><td>Runners Up</td></tr>
```

The `{{Home Team Year Report}}` template wraps this in a `<table>` automatically.

## Category

The template adds `[[Category:Home Teams]]` automatically via `includeonly`.
You do **not** need to add a category manually.

## Workflow

1. `get-page("Team Name")` — confirm the main team page exists and note the exact
   title spelling.
2. `get-page("YYYY:Team Name")` — if it exists, switch to update mode; if missing,
   create.
3. Fetch a sibling year page (e.g. `2025:Football Team`) to copy structure.
4. Read `Template:Home Team Year Report` for current fields.
5. Draft the page. For sports teams, fill `achievements` and `participations`.
   For cultural teams, fill `achievements` and `videos`. Leave `project`/`docs`
   blank.
6. Show the human the proposed wikitext and confirm before saving.
7. Save with summary: `Bot: Create 2026:TeamName yearly report — <agent>`.
8. Create the main-namespace redirect if it doesn't exist.

---

## Common mistakes to avoid

- Using a hyphen (`-`) instead of an en-dash (`–`) in the year field.
- Spelling the team name differently from the main team page title (breaks
  `{{Home Team Year Report}}`'s `== See also ==` link).
- Adding `[[Category:Home Teams]]` manually — the template does it; duplicates
  create Cargo noise.
- Editing the `{{#cargo_declare}}` block inside `Template:Infobox Home Team Year`.
